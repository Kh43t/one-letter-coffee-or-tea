## The letter

**A**

Coffee. Tea is patient and polite and waits its turn; coffee answers
back — black, bitter, steaming, already working before you are awake.
"A" opens the alphabet, so the first letter names the first drink of
the day: the honest answer of anyone who has ever needed to be awake,
and the funniest one too, because nobody has ever joked about needing
tea to function.

## Run it

```sh
node main.ts
cat /output/entry.txt
# A
```

`main.ts` writes exactly one character, `A`, to `/output/entry.txt` —
1 byte, no newline, no punctuation, deterministic. No network, no
environment reads, no dependencies.
